Deep-pull a specific commander

The general corpus samples broadly across all commanders, so any one commander usually only has a handful of decks. This pulls up to target real Archidekt decks filtered specifically by commander name, appends them to the corpus, and automatically re-runs Stages 2-5 so the Explorer reflects the new decks when it's done.

Simulate

Run the Monte Carlo simulator directly on specific decks -- built for testing your own decks, which may not be in the sampled corpus at all. Import any Archidekt deck by URL, pick it as "Your deck", then either stress-test it alone or race it against up to three opponent decks. Table simulation is not a real interactive Magic simulator -- there's no stack, no targeting, no blocking. Each deck's game is simulated independently and compared afterward; the "disruption chance" is a single rough estimate from the table's interaction density, not a play-by-play prediction. See the full report for exactly what is and isn't modeled.
